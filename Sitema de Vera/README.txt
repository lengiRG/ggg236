SISTEMA ACADEMICO - PRACTICA 1

Basado en los procesos indicados en la guia PDF:
1. Estructura y organizacion por carpetas.
2. shared/ con ArchivoJSON y validaciones.
3. models/ con Estudiante, Docente, Asignatura y Curso.
4. controllers/ con un controlador CRUD para cada modelo.
5. views/ con InterfazConsola.
6. main.py con SistemaAcademico y menu principal.
7. data/ con archivos JSON.

Ejecutar:
    python main.py

NOTA:
El PDF enumera las clases Docente, Asignatura y Curso, pero no especifica sus
atributos. Para completar el proyecto de forma sencilla se usaron:
Docente: nombre, apellido, email.
Asignatura: nombre, codigo.
Curso: nombre, paralelo.
